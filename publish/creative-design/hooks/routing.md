The creative-design skills are installed. Load the named skill with the Skill tool before the matching work.

| When | Skill |
|---|---|
| Open-ended design talk: starting a design, brainstorming, the talk drifting into detail too early | creative-design:layered-design-facilitation |
| The user states decisions, ideas or answers that belong in the design docs | creative-design:design-capture |
| Setting up a new docs project; running or changing the docs lint; the system map | creative-design:doc-kit |
| Reorganizing existing docs: splitting a file, deciding where something goes | creative-design:structured-project-docs |
| A finished task, open decisions or an explanation that is easier to judge on a page than in chat | creative-design:handoff |

Usual order in a design project: doc-kit once for the setup, then facilitation and capture in turns, handoff at checkpoints. A project's own conventions file takes precedence over this table.
