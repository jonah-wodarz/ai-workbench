# Archery
> Ranged combat with bows. Arrows are a scarce resource.
> - A hunting bow fires one arrow per draw.
> - Every arrow fired is consumed on impact.

## Intent
Archery gives the player a quiet, costly way to engage threats at range. It serves VIS-P1 (scarcity): each arrow spent is a decision, and VIS-P3 (quiet tension).

## Rules
### Firing
- **ARC-R1** A hunting bow fires one arrow per draw. `locked`
- **ARC-R2** Every arrow fired is consumed on impact. `locked`

### Damage
- **ARC-R3** A hit on an unarmoured target deals more damage than a hit on an armoured target. `locked`

## Parameters
None yet.
