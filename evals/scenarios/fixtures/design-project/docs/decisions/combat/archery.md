# Archery — decision history
Current state: [`../../design/combat/archery.md`](../../design/combat/archery.md). Entries record pivotal decisions only, are immutable, and run newest at the bottom.

### D-ARC-001 — Arrows are consumed on impact
2026-10-02 · accepted · rules ARC-R2
**Decision:** Every arrow fired is consumed on impact; none can be picked up again.
**Why:** Recoverable arrows make ammunition effectively free, which breaks VIS-P1 (scarcity).
**Rejected:** Recoverable arrows from walls and corpses — ammunition stops being a decision; breakable arrows with a recovery chance — hides the cost behind randomness.
