# Weather — decision history
Current state: [`../../design/world/weather.md`](../../design/world/weather.md). Entries record pivotal decisions only, are immutable, and run newest at the bottom.

### D-WEA-001 — The forecast is always correct
2026-11-10 · accepted · rules WEA-R2
**Decision:** The forecast never lies.
**Why:** A wrong forecast makes a loss feel like bad luck, which breaks VIS-P2.
**Rejected:** A forecast that is sometimes wrong — more tension, but losses stop being traceable to a choice.
