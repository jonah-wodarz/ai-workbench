# Playbooks
Repeatable workflows, each worked out by trial and error at least once. A playbook holds the current steps; its run log in [`runs/`](runs/) holds what was tried and why. Written and refined by the [playbook skill](../skills/playbook/SKILL.md); a playbook that stays stable over 3+ runs becomes a skill candidate.
